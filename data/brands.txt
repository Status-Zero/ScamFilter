# Brands scammers impersonate: a keyword, then the brand's official domains (comma-separated).
# Used for display-name checks ("PayPal Support" <x@gmail.com>) and look-alike domain checks.
#
# Format:   keyword|Name to show   domain1, domain2, ...
#   - the keyword is what's searched for: lowercase letters and digits only
#   - the name after | is how the app writes the brand ("PayPal", not "paypal"); optional
#
# Rules:
#   - keywords with 6+ letters match anywhere in a domain ("paypal" in "paypal-secure.com")
#   - keywords with 5 or fewer letters must match a whole piece between dots/dashes
#     ("ups" matches "ups-track.com" but not "groups.com"); add variants like "appleid" when needed
#   - a brand's name on a major country domain (amazon.de, google.co.uk) counts as official,
#     so those don't need listing
#   - never list a free-mail domain (gmail.com, outlook.com, icloud.com...) as official:
#     anyone can make an address there
